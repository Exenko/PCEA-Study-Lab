# Shop Idle Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Running Workshop pipelines earn cash into per-desk outboxes, including while the app is closed. The learner collects by hand, buys firm upgrades and study aids, and idle earnings never become XP.

**Architecture:** A pure `js/shop/idle.js` (`ShopIdle`) derives desks, outboxes and collects from timestamped shop records, with `now` passed in. `ShopCore.state()` stays the single source of cash, adding `collect` amounts and subtracting `upg` costs. A new `js/shop/firm.js` (`ShopFirm`) renders the desk panel, the ticking outboxes and the upgrade shop. `workshop.js` and `ui.js` gain shift toggles, tier re-test chips, hint and reroll.

**Tech Stack:** Vanilla JS IIFEs (`module.exports` in Node, globals in the browser), Node `assert` tests via `tests/run.js`, and plain CSS using the tokens in `css/styles.css`.

**Spec:** `docs/superpowers/specs/2026-09-24-shop-idle-design.md`

**Deviations from spec (decided while planning):**
- **`idle.js` depends only on `ShopCore`.** It reads pipe records directly (`d.shop['pipe-' + id]`) instead of going through `ShopPipe`.
- **The shift record also stores `off: string[]`.** These are pipelines the learner turned off, so auto-fill never puts them back.
- **`setShift` keeps the existing `off` list.** It adds only the pipelines removed in this call and drops any that are being turned back on.
- **New `buyUpgrade(d, id, now)` returns the writes for a purchase.** A desk purchase first writes a shift snapshot that pins the current desks' `since`. Without that, the new desk-upgrade `t` would push every auto-filled desk's start forward and wipe accrued outboxes.
- **Collect records also carry `t: now`,** because `state()` orders records by `t`.
- **The firm panel and upgrade group show only once at least one pipeline is running.** Before that, the Workshop panel already explains the path.

## Global Constraints

- Money is in \$K. Gross per hour = `0.25 x ShopCore.BASE[tier]`. Upkeep per hour = `0.5 x stepCount`. Net = `max(0, gross x mult - upkeep)`. Collected amount = `round1(net x min(capHours, hours))`.
- Desks = `2 + desk level`. Cap hours = `[8, 12, 16, 24][cap level]`. Mult = `1 + 0.25 x analyst level`.
- Upgrade cost of the next level: desk `300 x 2^k`, cap `[250, 500, 1000][k]` (max 3 levels), analyst `400 x 2^k`.
- Consumables: `hint` costs 60 and `reroll` costs 50, both `consumable: true`.
- Collect key is `collect-<tplId>-<start>`, and the record is `{ collect, from, to, amount, t }`.
- Idle records (`collect`, `upg`, `shift`) never carry `tpl` or `camp`. They never change XP, completed jobs or reputation.
- With 0 rerolls, `offers()` seeds are identical to today: `hash(profile|completed|slot)`.
- UI placeholders use CSS tokens only, so dark mode works. No horizontal page scroll at phone width.
- Tests: `npm test` runs everything; `node tests/run.js <substring>` runs one file.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Buying a desk must not reset outboxes already accruing.** `buyUpgrade('desk')` pins the current desks before the upgrade record lands (tested in Task 3).
2. **A pipeline the learner turned off stays off.** It does not come back when a desk is bought or another pipeline passes (Task 3).
3. **Clock moved backwards, or `now` earlier than the start:** the outbox is 0, never negative (Task 3).
4. **Double-tapping Collect, or collecting on two devices:** the second collect from the same start is `null` locally, and a merge keeps one record (Task 3).
5. **Re-passing a pipeline that is on shift:** time already accrued is banked at the old rate before the new record lands. After that, the outbox counts from the collect at the new rate (pure test in Task 3, UI order in Task 5).

### Task 3: Idle engine

**Files:**
- Create: `js/shop/idle.js`
- Create: `tests/fixtures/load-store.js`
- Create: `tests/idle.test.js`

**Interfaces:**
- Consumes: `ShopCore.BASE`, `ShopCore.state(d).cash` (Task 1).
- Produces: `ShopIdle = { HOUR, CAPS, UPGRADES, firm, running, onShift, rate, start, outbox, collect, collectAll, setShift, buyUpgrade }`.
  - `firm(d)` -> `{ desks, capHours, mult, levels: {desk, cap, analyst}, next: {desk, cap: number|null, analyst}, deskT }`.
  - `running(d)` -> the passed pipe records, sorted by `passedAt` (then `t`, then id).
  - `onShift(d)` -> `[{ id, since }]`.
  - `rate(d, id)` -> `{ gross, upkeep, net }`.
  - `start(d, id, since)` -> ms.
  - `outbox(d, id, now)` -> `{ amount, hours, full }`.
  - `collect(d, id, now)` -> `{ key, rec } | null`.
  - `collectAll(d, now)` -> `{ key, rec }[]`.
  - `setShift(d, ids, now)` -> `{ writes }`; throws `Error('Not enough desks')`.
  - `buyUpgrade(d, id, now)` -> `{ writes } | null`.
  - `UPGRADES` = `[{ id, name, desc }]` for desk, cap and analyst.
- The caller applies writes as `Store.data.shop[w.key] = w.rec`.

```js
  ];
  const r1 = v => Math.round(v * 10) / 10;
  const recs = d => Object.values((d && d.shop) || {}).filter(r => r && typeof r === 'object');
  const shiftRec = d => { const s = ((d && d.shop) || {}).shift; return s && typeof s === 'object' ? s : null; };
  const pipeRec = (d, id) => ((d && d.shop) || {})['pipe-' + id];

  function firm(d) {
    const levels = { desk: 0, cap: 0, analyst: 0 };
    let deskT = 0;
    recs(d).forEach(r => { if (r.upg in levels) { levels[r.upg]++; if (r.upg === 'desk') deskT = Math.max(deskT, r.t || 0); } });
    levels.cap = Math.min(levels.cap, CAPS.length - 1);
    return {
      desks: BASE_DESKS + levels.desk, capHours: CAPS[levels.cap], mult: 1 + 0.25 * levels.analyst, levels, deskT,
      next: { desk: 300 * Math.pow(2, levels.desk), cap: levels.cap < CAP_COST.length ? CAP_COST[levels.cap] : null, analyst: 400 * Math.pow(2, levels.analyst) }
    };
  }
  const running = d => recs(d).filter(r => r.passed && typeof r.pipe === 'string')
    .sort((a, b) => (a.passedAt || a.t || 0) - (b.passedAt || b.t || 0) || (a.pipe < b.pipe ? -1 : a.pipe > b.pipe ? 1 : 0));

  // Explicit shift entries first (earliest since wins a desk), then free desks auto-fill in pass order, skipping pipelines turned off.
  function onShift(d) {
    const f = firm(d), run = running(d), live = new Set(run.map(r => r.pipe)), sr = shiftRec(d);
    const off = new Set((sr && sr.off) || []), map = (sr && sr.shift) || {};
    const out = Object.entries(map).filter(([id, s]) => live.has(id) && Number.isFinite(s)).map(([id, since]) => ({ id, since }))
      .sort((a, b) => a.since - b.since || (a.id < b.id ? -1 : 1)).slice(0, f.desks);
    const floor = Math.max((sr && sr.t) || 0, f.deskT);
    for (const r of run) {
      if (out.length >= f.desks) break;
      if (!off.has(r.pipe) && !out.some(o => o.id === r.pipe)) out.push({ id: r.pipe, since: Math.max(r.passedAt || r.t || 0, floor) });
    }
    return out;
  }
  function rate(d, id) {
    const r = pipeRec(d, id);
    if (!r || !r.passed) return { gross: 0, upkeep: 0, net: 0 };
    const gross = RATE * (C.BASE[r.tier] || C.BASE[1]), upkeep = UPKEEP * (r.stepCount || 0);
    return { gross, upkeep, net: Math.max(0, gross * firm(d).mult - upkeep) };
  }
  const start = (d, id, since) => recs(d).filter(r => r.collect === id && Number.isFinite(r.to)).reduce((m, r) => Math.max(m, r.to), since);
  function outbox(d, id, now) {
    const o = onShift(d).find(x => x.id === id);
    if (!o) return { amount: 0, hours: 0, full: false };
    const f = firm(d), hours = Math.max(0, (now - start(d, id, o.since)) / HOUR);
    return { amount: r1(rate(d, id).net * Math.min(f.capHours, hours)), hours, full: hours >= f.capHours };
  }
  function collect(d, id, now) {
    const o = onShift(d).find(x => x.id === id);
    if (!o) return null;
    const b = outbox(d, id, now);
    if (!(b.amount > 0)) return null;
    const s = start(d, id, o.since);
    return { key: 'collect-' + id + '-' + s, rec: { collect: id, from: s, to: now, amount: b.amount, t: now } };
  }
  const collectAll = (d, now) => onShift(d).map(o => collect(d, o.id, now)).filter(Boolean);

  function setShift(d, ids, now) {
    const f = firm(d), live = new Set(running(d).map(r => r.pipe));
    ids = ids.filter(id => live.has(id));
    if (ids.length > f.desks) throw new Error('Not enough desks');
    const cur = onShift(d), next = new Set(ids), sr = shiftRec(d), removed = cur.filter(o => !next.has(o.id));
    const writes = [];
    removed.forEach(o => { const c = collect(d, o.id, now); if (c) writes.push(c); });
    const shift = {};
    ids.forEach(id => { const o = cur.find(x => x.id === id); shift[id] = o ? o.since : now; });
    const off = [...new Set([...((sr && sr.off) || []), ...removed.map(o => o.id)])].filter(id => !next.has(id)).sort();
    writes.push({ key: 'shift', rec: { shift, off, t: now } });
    return { writes };
  }
  // A desk purchase first pins the current desks, so the new upgrade time never moves their start.
  function buyUpgrade(d, id, now) {
    const cost = firm(d).next[id];
    if (cost == null || C.state(d).cash < cost) return null;
    const writes = id === 'desk' ? setShift(d, onShift(d).map(o => o.id), now).writes : [];
    writes.push({ key: 'upg-' + id + '-' + now, rec: { upg: id, cost, t: now } });
    return { writes };
  }

  const ShopIdle = { HOUR, CAPS, UPGRADES, firm, running, onShift, rate, start, outbox, collect, collectAll, setShift, buyUpgrade };
  if (typeof module !== 'undefined' && module.exports) module.exports = ShopIdle; else root.ShopIdle = ShopIdle;
})(this);
```
